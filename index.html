Studi Kasus 2: Email Tanpa Subjek Budi

Tugas Terabaikan Guru

Budi mengirim tugas TIK kepada gurunya via email. Namun Budi mengosongkan judul subjek, tidak menulis salam pembuka, dan langsung melampirkan file tanpa keterangan. Email Budi dianggap sebagai spam dan tidak dibaca oleh guru!

💡 Solusi TIK: Memahami tata krama surel (netiquette) dengan mengisi Subject, Salam, Pesan Pembuka, dan Nama Pengirim.

Materi Pembelajaran TIK Kelas 7

1. Antarmuka Pengguna (User Interface)

Antarmuka Pengguna adalah media interaksi antara manusia dengan perangkat komputer:

  • • GUI (Graphical User Interface): Antarmuka grafis berupa ikon, tombol, dan jendela (contoh: Windows, Android, macOS).
  • • VUI (Voice User Interface): Antarmuka perintah suara (contoh: Google Assistant, Siri).
  • • CLI (Command Line Interface): Antarmuka berbasis teks perintah ketik (contoh: Command Prompt/CMD).
  • • Touch & Gesture: Antarmuka layar sentuh dan gerakan tangan.

2. Pengelolaan Folder dan File

File dikelompokkan ke dalam direktori/folder secara terorganisir:

Ekstensi File Utama:

• Dokumen Teks: .docx, .pdf, .txt

• Gambar: .jpg, .png, .svg

• Lembar Kerja: .xlsx | Audio/Video: .mp3, .mp4

Operasi File: Cut (pindah), Copy (gandakan), Paste (tempel), Rename (ubah nama), Delete (hapus).

3. Peramban Web vs Mesin Pencari

Beda Peramban Web (Browser) dan Mesin Pencari (Search Engine):

  • • Peramban Web (Browser): Perangkat lunak untuk membuka halaman internet (contoh: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
  • • Mesin Pencari (Search Engine): Program berbasis situs web untuk mencari informasi berdasar kata kunci (contoh: Google Search, Bing, Yahoo).

4. Surat Elektronik & Netiquette

Komponen Email dan Etika Berkomunikasi:

To: Alamat email penerima utama.

CC (Carbon Copy): Penerima tembusan (diketahui bersama).

BCC (Blind CC): Tembusan rahasia (penerima lain tidak melihat).

Attachment: Lampiran file dokumen/foto.
